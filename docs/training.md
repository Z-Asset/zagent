# Zagent 模型训练的思路

本文讲清楚 zagent 的 Model-RSI 到底在训练什么、怎么训、为什么这么训。面向非量化背景的同事和学生，用大白话 + 必要的技术准确度。

## 一句话

用「过去 L 天的因子」预测「明天的收益」，用滚动时间序列回测（walk-forward）验证，用 TPE 搜索最优训练配方。

## 数据：一块面板

```
X (T, N, K)  =  T 个交易日 × N 只股票 × K 个因子
Y (T, N)     =  每天的次日收益（要预测的目标）
```

- T 个交易日，例如 2833 天（约 11 年）
- N 只股票，例如 379 只中证500成分股
- K 个因子，例如 54 个（动量、反转、波动、估值、技术指标…）

## 清洗：逐日截面，防前视

对**每个交易日独立**、对**每个因子独立**，按顺序做：

1. **去极值**（clip）：把当天这个因子的极端值拉回边界（3MAD 或分位数）
2. **截面标准化**（zscore）：减当天均值、除当天标准差
3. **缺失值中位数填充**：最后填，用当天截面中位数

**为什么顺序不能乱、为什么必须逐日**：金融数据有厚尾（极端值）和缺失，且只能用**当天**的统计量。一旦用了"整个样本期"的均值或"未来"的值，就是前视泄漏——回测好看、实盘必崩。

## 切样本：序列窗口

要预测「t+1 天的收益」，模型看的是「t-L+1 到 t 天」这段因子序列（一个 `(L, K)` 的时间窗，L 默认 60 天）。

**前视红线**：窗口必须**结束于 t**。绝不能用 t 之后的特征。代码里的 `seq_index(t, L)` 就是专门防这个的——S13 项目历史上曾因此出过 59 天前视的重大 bug，整批结果作废。

## 训练：walk-forward 滚动回测

不是训练一次，而是把时间轴切成 123 个块，**每块模拟一次"用过去预测未来"**：

```
[ 训练段 ]  拟合模型
[ 验证段 ]  独立选超参（绝不碰测试块）
[ 测试块 ]  预测"未来"收益，打分
```

- 每向前走一块，训练窗**扩张**一块（expanding）
- 训练/验证 与 测试块之间留 **2 天空白**（GAP=2），隔离样本内外
- 这一步等价于"站在每一天，只用截至当天能拿到的信息去预测明天"，是真实交易场景的忠实模拟

## 评估：不只看预测误差，看能不能赚钱

- **OOS_RankIC**（主指标）：每天把「预测排名」和「实际收益排名」做秩相关。>0 表示预测排序有用，0.05-0.1 是不错的 alpha
- **OOS_ICIR**：RankIC 的稳定性（均值/标准差）
- **OOS_SR**：按预测加权的组合夏普比率

只看**样本外（OOS）**。训练集上再好不算数，测试块才是"没见过的未来"。

## 进化：Model-RSI 找更好的配方

上面的步骤是"训练一个模型"。Model-RSI 要的是"找更好的模型"：

```
配方(超参) → 训练 → 评估 → 得到 RankIC
     ↑                          ↓
  TPE 提议新配方  ←  历史 RankIC 喂给搜索器
```

循环直到只剩严格更优的配方、或连续几轮无改进早停。

三个角色分工：
- **Operator**：确定性训练脚本，按配方跑 walk-forward
- **Evaluator**：算 RankIC（封闭，Refiner 看不到、改不了）
- **Refiner**：TPE 贝叶斯搜索，读历史指标提议下一组超参

## 为什么是这个思路：金融数据的三个特殊性

1. **前视是头号敌人**：金融数据时间相关性强，任何"偷看未来"都会让回测虚高、实盘崩。GAP=2、序列切窗、逐日截面清洗，全是防这个。
2. **样本外才是真**：walk-forward 的测试块是"没见过的未来"，RankIC 必须看 OOS。
3. **信号弱、噪声大**：次日收益几乎不可预测。RankIC 0.05-0.1 就是不错的结果，别期待图像识别那种 90% 准确率——这是这个领域的真实天花板。

## 关于"最优"

zagent **不保证**找到全局最优模型，只保证：
- 搜索聪明（TPE 贝叶斯，不是随机/网格）
- 评估干净（封闭、防前视、看样本外）
- 接受严格（只保留严格更优，可审计可回滚）

"最优"的最终上限由两件事决定：硬件时间（GPU 能多跑几轮）+ 数据本身的信号强度（S13 是教学复刻数据，RankIC 天花板本来就不高）。
